# SuOrganiza

Aplicativo de controle financeiro pessoal.

## Publicação

Este projeto é uma página HTML estática e pode ser publicado na Vercel.

## Banco de dados

O projeto usa Supabase para autenticação e persistência dos dados.

1. Crie o projeto no Supabase.
2. Execute `supabase_setup.sql` no SQL Editor.
3. Configure a URL e a chave publicável no `index.html`.

> Nunca coloque uma chave `sb_secret_...` no código do navegador.

## Desenvolvimento local

Abra `index.html` no navegador ou sirva a pasta com um servidor local.
